Для создания этого проекта Yatube я использовал следующие технологии:

Python и Django

Django - мощный фреймворк для создания веб-приложений. Он предоставляет множество готовых компонентов: ORM для работы с базами данных, систему аутентификации пользователей, шаблонизатор и многое другое.

HTML/CSS и Bootstrap

Bootstrap позволил быстро создавать адаптивный интерфейс, который хорошо выглядит на всех устройствах. Я научился работать с компонентами Bootstrap: navbar, cards, forms и другими.

База данных

В проекте используется PostgreSQL - надежная и мощная база данных. Django ORM делает работу с ней очень удобной.

Git

Git помогает управлять версиями проекта и сотрудничать с другими разработчиками. Я освоил основные команды: commit, push, pull, branch, merge.

Что было сложным?

Наиболее сложным было понимание работы Django ORM и создание правильных связей между моделями. Также требовалось время, чтобы понять систему шаблонов и контекста в Django.

Что было интересным?

Создание системы пользователей и аутентификации оказалось очень интересным процессом. Также было увлекательно работать с Bootstrap и создавать адаптивный интерфейс.
